# 星图 · Xingtu

一个在浏览器中运行的交互式天象仪。使用真实 Tycho-2 星表、Three.js 自定义着色器和 astronomy-engine，在本地计算指定时间与地点的星空；默认场景为当前时间的中国上海。

> **许可提示：**代码采用 MIT，但星表数据采用 **CC BY-NC 3.0 IGO**，含非商业限制。代码许可不覆盖任何外部数据，商用或再分发前必须分别核对下方各数据许可。

## 功能

- 当前构建包含 **2,557,501 颗真实恒星**，亮星全天加载，暗星按 HEALPix 天区按需加载。
- 球心视角、立体投影、拖拽惯性、滚轮与双指缩放；FOV 范围为 0.25°–160°。
- 自定义星点 `ShaderMaterial`：星等控制尺寸与亮度，B−V 控制颜色，带柔和光晕。
- 在 GPU 顶点着色器中完成恒星自行、周年光行差和坐标旋转，不逐帧遍历整个星表。
- 可设置经纬度和 UTC 时间，暂停或以正反向多档速率运行模拟时钟。
- 地平线、地面遮挡、方位标记，以及可独立开关的地平网格和赤道网格。
- 太阳、月球和除地球外的七颗行星；地球是观测者，不作为天空目标显示。
- 亮星名称、88 个西方星座、中国星官、三垣与二十八宿；标签随 FOV 调整并避免屏幕碰撞。
- DSS2 Color HiPS 银河背景，以及由单个滑块控制的大气消光、日光和月光天光。
- 点选天体查看编号、星等、坐标、距离和相位等信息；通过 URL 还原完整观测场景。

## 环境与启动

需要：

- Node.js 20.19 或更高版本；
- pnpm 12.6.0（`package.json` 已固定 `packageManager`）；
- 支持 WebGL2 的现代浏览器；
- 下载星表及加载在线 DSS2 HiPS 时的网络连接。

首次运行必须先下载并构建本地数据：

```bash
pnpm install
pnpm data:download
pnpm data:build
pnpm dev
```

打开 `http://localhost:5173/`。开发服务器默认监听 `0.0.0.0:5173`，也可显式运行：

```bash
pnpm dev --host 0.0.0.0
```

`data:download` 会复用已完整下载的文件，并对支持 Range 的星表分卷使用 `.part` 文件断点续传。原始数据放在 `data/raw/`，生成数据放在 `public/data/`；两者均已加入 `.gitignore`，不会提交到仓库。

也可分步执行预处理：

```bash
pnpm data:stars           # 必须先运行，生成星表、星名和参考恒星
pnpm data:constellations  # 复用参考恒星，生成星座连线与二十八宿
```

重复构建会覆盖 `public/data/` 中对应的生成文件。构建日志逐文件输出星数和字节数，并打印汇总；完整逐文件统计也写入 `stars-manifest.json`。

## 操作

- 鼠标拖拽或单指拖动：转动视角；滚动滚轮或双指捏合：改变 FOV。
- 点击天体：打开信息卡；点击空白区域或关闭按钮：清除选择。
- 画布获得键盘焦点后，方向键移动，`+` / `-` 缩放，Enter 选择视野中心的天体。
- “复位视角”恢复方位 180°、高度 32°、FOV 75°，不会改变地点或时间。
- 地点预设仅按北半球和南半球分组，也可直接输入自定义经纬度；经度向东为正。
- 时间输入使用 UTC，面板下方同时显示对应地点的本地模拟时间。
- “分享视角”复制地点、ISO 时间、视角、FOV、时钟状态及图层设置。浏览器需要剪贴板权限；拒绝权限时会显示失败提示。

分享 URL 使用 `v=1` 版本标记，参数包括 `lat`、`lon`、`time`、`az`、`alt`、`fov`、`paused`、`rate`、`cn`、`west`、`hor`、`eq`、`hips`、`labels` 和 `air`。带版本标记的链接若有参数缺失或非法，会整体回退到默认场景，而不是只恢复一部分状态。

- 星表二进制总计 **102,300,040 字节**，约 97.6 MiB。
- 暗星使用 **HEALPix NESTED order 3**，只请求覆盖当前视锥的切片。
- 请求按分块去重，下载后校验字节数和记录数；缓存上限为 160 MiB，超限时淘汰不再使用的暗星天区。

- 三垣总标签由对应左右垣墙的唯一端点视位置动态求中心，不使用固定的过期坐标。

### 恒星二进制格式

`.bin` 文件是无文件头的 float32 记录流，与浏览器的 `Float32Array` 布局对应。每颗星 10 个 float32，即 **40 字节**：

| 偏移 | 字段         | 含义                                                     |
| ---: | ------------ | -------------------------------------------------------- |
|  0–2 | `x y z`      | J2000 赤道坐标单位球方向                                 |
|  3–4 | `pmRa pmDec` | 赤经方向切向自行（含 cos δ）和赤纬自行，rad/year         |
|    5 | `magnitude`  | 近似 Johnson V 视星等                                    |
|    6 | `colorIndex` | 近似 Johnson B−V                                         |
|    7 | `hip`        | HIP 编号；无编号时为 0                                   |
|    8 | `tyc1`       | TYC 第一段编号                                           |
|    9 | `tyc2Packed` | `tyc2 × 4 + tyc3`，避免完整编号超出 float32 整数精确范围 |

TYC 显示时解码为 `TYC ${tyc1}-${floor(tyc2Packed / 4)}-${tyc2Packed % 4}`。

预处理会校验必需字段、过滤无效记录和已命名的太阳记录，将非 J2000 位置先按自行传播回 J2000。BT/VT 到 Johnson 测光的换算采用近似公式：

```text
V   = VT − 0.09 × (BT − VT)
B−V = 0.85 × (BT − VT)
```

只有一种测光值可用时以其近似 V；无法计算色指数时使用 0.65 作为显示默认值。这些换算用于视觉呈现，不应替代正式测光星表。

## 架构

```text
src/
  astro/    纯天文计算：坐标、时钟、星历、光行差、大气、HEALPix、投影
  data/     星表解析、分块缓存、元数据、地点和 HiPS 客户端
  render/   Three.js 场景、共享着色器、星点/网格/星座/背景/行星和拾取
  ui/       观测控件、标签、信息卡、URL 和 DOM 工具
  main.ts   应用组合与动画循环
scripts/    数据下载和预处理
tests/      Vitest 单元与回归测试
public/data/ 本地生成且不入库的数据
data/raw/    本地下载且不入库的原始数据
```

`astro/` 不依赖 Three.js，可在 Node 中独立测试。天空对象统一使用单位球方向，避免真实距离造成 GPU float32 精度问题。渲染层共享观测坐标矩阵和立体投影；星座连线端点与恒星采用相同的自行和光行差计算。

点击拾取只在点击发生时执行：先检查日月中行星，再检查当前已加载且被 FOV 激活的恒星分块，不进行每帧全星表搜索。

## 精度与当前边界

- 恒星从 J2000 方向按切向自行传播，并应用基于地球质心速度的相对论周年光行差；岁差、章动和地平转换由 astronomy-engine 的旋转矩阵完成。
- Vitest 包含独立 Stellarium 参考回归：2024-01-01T16:00:00Z、上海，天狼星无大气折射的几何地平坐标与参考方位/高度误差必须小于 0.1°。该测试不意味着所有恒星都具有相同的绝对星表精度。
- 绝对精度仍受 Tycho-2 原始观测误差、缺失自行和历元处理限制。当前未加入视差、径向速度、透视自行或双星轨道；长期线性外推不等于完整天体测量模型。
- 不计算大气折射，因此尤其是近地平区域，显示方向会与实际折射观测不同。大气消光、日光和月光为可调的视觉近似，不包含天气、地形或光污染模型。
- 色温和光晕是视觉映射；近似 B−V 不用于科学测光。
- HiPS 当前读取 order 0 的 12 张全天切片，并按 HEALPix NESTED 解码到 1024×512 赤道纹理。它是低分辨率全天背景，不会随着放大加载高阶细节，也不用于测光。
